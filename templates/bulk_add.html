📋 Instructions & Formatting Guidelines
  • Supported Files: Microsoft Excel (.xlsx) and Comma-Separated Values (.csv).
  • Required Header Column: village (or village_name).
  • Optional Header Columns: farmer_name, phone_number, address, survey_number, sample_source (govt or private), scheme, crop, testing_fee, collection_date.
  • Automatic Sample ID: SoilTrack auto-assigns village-based sequential Sample IDs (e.g. RAT-01, RAT-02) for all imported rows.
